# Cashiers Report UI Rules

## Purpose

Use these rules whenever creating or modifying the Cashiers Report interface.

## Layout

Cashier Report:
- "Today's Summary" is always in left. When the screen is small, it will hide but with a right floating button to unhide
- Expenses, Income, Payment must have the same layout and spaces.
- When the Screen is small, the Right and Left sidebar will hide. 

## Forms

- All input form is always a **right-side shadcn Sheet drawer** when the screen is small.

## Right Drawer Standard
