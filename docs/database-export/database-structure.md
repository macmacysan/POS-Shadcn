# Cashiers Report SQLite database structure

Read-only physical-schema inventory. Actual migration version: **46**; current source migration version: **46**.

## Conventions

- The app opens this one SQLite database in the Electron main process through `better-sqlite3` and enables foreign keys and WAL mode.
- IDs are usually `TEXT` UUIDs generated by application/import code; exceptions and composite/natural keys are listed per column.
- Money is stored as integer centavos. Dates are `YYYY-MM-DD`; timestamps are ISO-8601 UTC strings.
